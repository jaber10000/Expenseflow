# 💰 ExpenseFlow

A full-stack personal finance management web application built with React, FastAPI, and PostgreSQL.

## ✨ Features

- JWT Authentication
- Income & Expense Tracking
- Transaction Management
- Financial Dashboard
- Savings Insights
- Multi-Currency Support

## 🛠 Tech Stack

- React + TypeScript
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT
- Vercel
- Render

## 🚀 Run Locally

### Backend

```bash
cd backend
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
